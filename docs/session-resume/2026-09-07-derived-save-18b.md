# 2026-09-07 — 파생 팔레트 저장을 화면에 잇는다 (18단계 · 18-B)

[18-A](2026-09-07-derived-save-18a.md) 가 만든 저장 경로(`POST /api/saved/derived`)를 화면에
잇는다. **이것으로 A1("파생 팔레트를 저장 못 한다")이 닫힌다.**

## 사용자가 보는 변화

**전:** 펼쳐서 나온 배색 여덟 장을 보고 슬라이더로 면적까지 맞출 수 있는데 **남길 수가 없었다.**
새로고침하면 사라진다.

**후:** 카드마다 `[이 배색 저장]` 버튼이 생겼다. 누르면 `/saved` 에 남고 거기서 다시 꺼내
비율을 고칠 수 있다.

```
/saved 의 파생 항목
  보색대비                        [어두운 배경]
  씨앗 자홍 × 진파랑   출처 1절 기법표
  색상환에서 180° 벌린다. 충돌하고 생생하며 역동적이다.
  ▬▬▬▬▬▬ 60%   ▬▬ 20%   ▬▬ 20%      ← 색마다 슬라이더
```

**슬라이더로 맞춘 비율이 그대로 넘어간다.** 홈에서 60/20/20 으로 맞추고 저장하면 `/saved` 에도
60/20/20 이다(브라우저 실측).

## 세 가지를 고쳐야 했다

### 1. `/saved` 가 코퍼스 항목만 있다고 가정했다

`entry.type`·`hueRelation`·`summary` 를 그냥 읽고 있었다. 파생에는 그런 필드가 없으니 화면에
**`undefined형`** 이 떴을 것이다.

무엇을 보여줄지 정하는 부분을 **`savedFields` 라는 순수 함수**로 뺐다. **이유는 게이트다** —
`/saved` 는 브라우저 화면이라 정적 검사밖에 못 하는데 정적 검사는 "무엇이 화면에 나가는가" 를
못 본다. 함수로 빼면 게이트가 그냥 불러서 대조한다.

17단계에서 `structureColors` 를 뺀 것과 **같은 이유**다. 그때 정적 검사가 `dark`/`light` 를
뒤바꾼 변형을 못 잡았다.

### 2. 비율을 숫자 하나로 보내고 있었다

```js
api("/api/saved/ratio", { id, ratio: next[0] })   // ← 2색에서만 맞다
```

3~4색에서는 `next[0]` 이 **첫 색의 지분일 뿐**이라 나머지를 잃는다. 이제 언제나 배열로 보낸다.

### 3. 다색 슬라이더에 저장 시점이 없었다

`shareControl` 은 `onInput` 만 있었다 — 움직이는 동안만 알려 주고 **놓았을 때를 안 알려 준다.**
`onCommit` 을 붙였다. `input` 마다 저장하면 슬라이더를 끄는 동안 요청이 수십 번 나간다.

## 격리 리뷰 두 건 — Critical 0 · **High 3** · Medium 3 · Low 2

두 리뷰어가 **각각 Block/High 를 냈고 셋 다 실재했다.**

### High 1 — 항목 하나가 목록 전체를 지운다

`savedCard` 가 `entry.colors.map(...)` 을 가드 없이 부른다. `colors` 가 없는 항목이 있으면
`TypeError` 가 나고, 그 예외가 `load()` 의 `catch` 로 튀어 **목록을 통째로 비운다.**

```
전: colors 없는 항목 1개 → "불러오지 못했습니다" (나머지 전부 사라짐)
후: 그 항목만 "이 항목을 그리지 못했습니다", 나머지는 그대로
```

**이 작업이 세운 AC 와 정면으로 충돌했다.** "필드가 빠진 항목에서도 undefined 가 안 샌다" 를
목표로 `savedFields` 를 만들어 놓고 **표시 문자열만 막았다** — 색은 그 바깥이었다.
`savedFields` 가 색도 정규화하게 했고, `load()` 에 항목별 `try/catch` 를 이중 방어로 뒀다.

### High 2 — 다색 저장이 실패해도 슬라이더가 안 돌아온다

`shareControl` 이 `{ node, shares }` 만 돌려줘서 **되돌릴 방법이 없었다.** 2색 경로
(`ratioControl`)는 `set` 을 주고 실패 시 되돌리는데, 다색 경로는 스와치만 되돌아가고
슬라이더는 실패한 값에 남는다 — 화면에 **두 비율이 동시에** 보이고, 다음 조작이 되돌아가지
않은 값을 기준으로 계산된다.

`set` 을 추가하고 `if (!ok) control.set(current)` 를 붙였다.

### High 3 — 내보내기가 파생을 조용히 망가뜨린다

내보내기(`src/export.js`)는 코퍼스 전제로 쓰였다. 파생을 넣으면 실측으로 이렇게 나왔다:

```
--undefined-ground        paletteId 가 없어 파생 항목마다 이름이 같아지고 서로 덮어쓴다
--undefined-undefined     rolesOf 가 앞 두 색만 봐서 3·4번째 역할이 없다
보색대비 · undefined형     코퍼스 전용 필드가 주석에 그대로
출처: 와다 산조 『배색사전』  ← 파생은 거기서 온 것이 아니다
```

**18-A 문서에 이 한계를 적어 뒀지만**("내보내기가 파생을 아직 모른다 — A2 가 그 자리다")
**18-B 가 그 경로를 버튼 한 번으로 닿게 만들었다.** 전에는 `curl` 이 필요했다.
게다가 나는 README 에 *"파생 팔레트… CSS 변수·JSON 내보내기"* 라고 **과장해 적었다.**

빼고, **뺐다고 말한다.** CSS 는 맨 위에 한 줄, JSON 은 `skippedDerived` 숫자로.
제대로 내보내는 것은 A2 다 — 재질 수치를 어떤 형식으로 줄지가 함께 정해져야 한다.

### Medium

| 지적 | 조치 |
|---|---|
| 다색 커밋에 경합 가드가 없다 — 슬라이더 여럿이라 응답이 순서대로 안 온다 | 표(`ticket`)를 뽑아 마지막 것만 반영. 같은 파일의 `noteField` 가 이미 쓰던 패턴 |
| `noteField` 가 `entry.name` 을 직접 읽어 `"undefined 조합의 메모"` 가 스크린리더로 나간다 | 정규화된 제목을 넘긴다 |
| ~~`shareControl` 에 `set` 이 없다~~ | High 2 와 같은 것. 두 리뷰어가 각각 찾았다 |

### 문제없다고 확인된 것

대비를 다시 쟀다 — 저장 버튼 6.78:1 · 비활성 6.59:1 · 피드백 5.78:1 로 전부 4.5:1 위.
다색 슬라이더는 이미 `aria-valuetext` 로 `"역할 40%"` 를 읽어 준다. CSS 자손 선택자 없음.

## 다음에 할 일 — A2 (엔진 수치 내보내기)

이제 파생이 저장되므로 `/api/export` 가 집이 됐다. 정할 것 둘:

1. **파생을 어떤 형식으로 내보낼까.** 코퍼스와 변수 이름 규칙이 다르다 — `paletteId` 대신
   `씨앗-구조-모드` 를 써야 하고, 역할이 3~4개다.
2. **재질 수치를 함께 낼까.** `applyFinish` 가 만드는 base·metallic·roughness·emission 을
   내보내려면 **저장 시점에 재질 배정도 함께 남겨야 한다** — 지금은 안 남긴다.
   그리고 언리얼·유니티 중 어느 쪽 표기로 낼지도 정해야 한다(`toUnity`/`toUnreal`).

## 열려 있는 것

- **저장에 재질 배정이 안 남는다.** 파생을 저장해도 "강조 = 발광" 은 안 남는다. A2 의 선행이다.
- **파생 항목이 200개 상한을 코퍼스와 나눠 쓴다.** 지금은 멀어서 안 닿는다.
- **`savedFields` 가 문자열 길이를 안 자른다.** 저장 시점에 `store.js` 가 자르므로 정상
  경로로는 안 들어오지만 손상된 파일에는 있을 수 있다. XSS 는 아니다(전부 `textContent`).
- **`S18-G9`·`S18-G11` 의 정적 부분은 표기만 본다.** 요청 본문을 별도 변수로 조립해 호출부
  밖에서 색을 주입하면 우회한다. `S18-G1`(서버가 색을 무시한다)이 실질 방어다.

## 함정 기록

- **"undefined 를 막는다" 는 표시 문자열만으로 안 끝난다.** 화면이 읽는 **모든** 필드가 대상이다.
  색을 빼먹었고, 그것이 목록 전체를 지웠다.
- **새 컨트롤을 만들면 기존 것이 주는 것을 전부 주는지 본다.** `ratioControl` 은 `set` 을 주는데
  `shareControl` 은 안 줬고, 그래서 실패 롤백이 반쪽이 됐다.
- **미뤄 둔 한계가 갑자기 닿기 쉬워질 수 있다.** 내보내기의 파생 미지원은 18-A 에 적어 뒀지만,
  18-B 가 버튼을 만들면서 `curl` 이 필요하던 경로가 클릭 한 번이 됐다. **문서에 적어 뒀다는
  것이 그대로 둬도 된다는 뜻은 아니다.**
- **살아 있는 목록은 그 자리에서 갱신한다.** 두 번 놓쳤다.
