## 왜 그렇게 했나

### 색인은 기동 시 1회

1단계 리뷰가 "요청마다 `createSearcher()` 를 부르면 병목"이라고 지적했고, 코퍼스가 정적이라
재색인할 이유가 없다. 기동에 실패하면 `CorpusError` 메시지를 내고 즉시 죽는다 — 반쯤 동작하는
서버를 띄우지 않는다.

### 화면이 실제보다 앞서 보이지 않게

디자인 초안에서는 6단계 사다리의 1·2단계가 칠해져 있었다. 그런데 질의 재작성은 아직 없다.
서버가 `stage: 1` 을 내려보내고 화면이 그 값을 그대로 그린다. 상단 배지도 `BM25 · 로컬 · 모델 없음`
이다. **화면이 자기가 실제로 하는 일만 말하게 하는 것**이 이 실험 사이트에서는 기능이다.

`confident`(어절 전체 매칭 유무)도 마찬가지로 숨기지 않는다. 저신뢰면 "못 잡음" 배지와
"아래 결과는 근거가 약하니 그대로 믿지 마세요" 를 띄우고, 매칭 항 중 어절 전체로 겹친 것만 굵게 쓴다.

### 스와치 글자색을 계산하는 이유

디자인 초안 리뷰에서 고정 색을 썼다가 4쌍이 대비 미달로 걸렸다. 이번엔 배경색마다 계산한다 —
1순위는 **그 색 자체를 태운 어두운 잉크**(검정에 색을 섞으면 바탕색이 더 선명해진다), 안 되면 흰색,
그것도 안 되면 순검정. 흰색과 순검정의 조합은 어떤 배경에서도 최소 4.58:1 을 보장한다.

`public/color.js` 로 분리한 것은 **브라우저 없이 검사하기 위해서**다. 게이트(S2-G5)가 코퍼스 32색
전부와 중간 회색에 대해 4.5:1 을 확인한다. 고정 색으로 되돌리면 32색 중 22색이 실패한다(실측).

### 경로 이탈 가드가 죽은 코드였다

게이트 4개가 첫 실행에 다 통과해서 의심하고 원시 소켓으로 두드렸다. **WHATWG URL 이 `/../` 를
서버에 닿기 전에 정규화**해 버려서 `resolve()+startsWith()` 가드가 한 번도 실행되지 않았다.
통과했지만 아무것도 검사하지 않은 것이다.

`serveStatic` 이 경로를 `decodeURIComponent` 로 풀도록 고쳤다(한글·공백 파일명을 위해 어차피 필요했다).
이제 가드가 실제로 일하고, 가드를 빼면 `/%2e%2e%2fserver.js` 가 **200 으로 서버 소스를 그대로 내준다.**
게이트에는 인코딩된 이탈만 넣었다 — 인코딩 안 된 `/../` 는 URL 정규화에 먹혀 가드를 검사하지 못한다.

## 남은 것 / 알려진 한계

- **HEAD·OPTIONS 가 405** 다. 로컬 실험 도구라 두고 간다.
- **경쟁 조건 수정에는 게이트가 없다.** 브라우저 없이 검사할 방법이 마땅치 않아 리뷰와 수동
  실측으로만 확인했다. 3단계에서 지연이 길어지면(모델 적재 51초) 이 경로가 다시 중요해진다.
- **Google Fonts 에 의존한다.** 오프라인이면 폴백(`system-ui`, `Malgun Gothic`)으로 떨어진다.
  로컬 우선 도구인데 폰트만 외부인 것은 어색하다 — 필요하면 서브셋을 `public/` 에 넣는다.
- 대화 내역·추천 받은 조합 탭은 `aria-disabled` 로 막아 뒀다(4단계).
