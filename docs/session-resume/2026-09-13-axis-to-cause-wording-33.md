# 2026-09-13 — "축" 을 "원인" 으로 (33단계 · 대표 지시)

## 무엇을 했나

대표 지시: "축이라는 단어를 사용하지 않고 다른 언어로 변경해줘". 바꿀 말을 물었고 **"원인"** 으로 정했다.

| 자리 | 전 | 후 |
|---|---|---|
| 맨 위 소개 | 왜 그런지 물으면 의심할 축을 답합니다 | … 의심할 원인을 답합니다 |
| 진단 결과 머리 | 색 조합이 아니라 어느 축을 의심할지가 답입니다 | … 어느 원인을 의심할지가 답입니다 |
| 진단 카드 | 의심할 축 — 톤축 (명도) | 의심할 원인 — 톤 (명도) |
| 연결된 조합 제목 | 이 축에 맞는 조합 — … | 이 원인에 맞는 조합 — … |
| 연결 없음 안내 | 이 축은 조합의 관계(색상각·톤)를 말하지 않습니다 | 이 원인은 … |
| 진단표 `axis` (3건) | 톤축 (명도) · 톤축 (채도) · 색상축과 톤축을 분리해서 보기 | 톤 (명도) · 톤 (채도) · 색상과 톤을 분리해서 보기 |
| 진단표 `detail` (3건) | 색상축과 톤축은 독립 변수다 · …독립이기 때문이다 · 조정할 수 있는 축은 색상각과 톤 두 개뿐 | 색상과 톤은 독립 변수다 · … · 조정할 수 있는 것은 색상각과 톤 두 개뿐 |

**그대로 둔 것**: "수축"(색이 줄어드는 성질 — `dx-stifling` · `pair-13`) · "축축하다"(`pair-13`)는 다른 낱말이다. JSON 필드
`axis` 와 CSS 클래스 `dx__axis` 는 내부 식별자다.

  바뀐 문장 전후 어디에도 그 어휘가 없다 `[실측]`.
