## 왜 그렇게 했나

### 색 (color-design 스킬 기준)

**명도 → 채도 → 색상 순서.** 색상부터 고르면 나중에 명도를 고칠 때 색상 선택이 통째로 무의미해진다.

1. **명도** — 배경 `#FBF7F2`(고명도) / 텍스트 `#241F1A`(저명도) / 중간톤은 보더 `#E7DED2` 하나.
2. **채도** — UI 전체를 저채도로 눌렀다. 이 사이트는 색을 *보여주는* 도구라, 화면에서 채도가 가장 높은 면은 **항상 추천된 스와치**여야 한다. 강조색을 쨍하게 만드는 게 아니라 나머지를 눌러야 하나가 산다.
3. **색상** — 강조 파랑 `#006EB8` 하나. 뉴트럴을 흰색이 아니라 따뜻한 아이보리로 깐 것은 배색사전 ⑩(살구+파랑)의 방식 — 차가운 색을 쓰면서 차가운 인상을 피한다.

**면적을 색의 일부로 취급했다.** 모든 스와치가 실제 면적 비율(78:22, 68:32 …)로 그려진다. 같은 두 헥스도 비율이 바뀌면 다른 색이 되므로, 비율 없는 5:5 칩은 색 도구에서 거짓말이 된다.

**버린 대안:** 다크 스튜디오(어두운 배경 위 팔레트) — 색이 실제보다 채도 높게 읽히는 부작용이 있어 색 판단용 도구에는 부적합. 웜 에디토리얼(강한 아이보리·살구) — 한색 계열 추천이 실제보다 차갑게 보임.

### 정보 구조

`docs/com/rag-is-simpler-than-you-think.md` 의 1~2단계(BM25 전문검색 + LLM 질의 재작성, 벡터DB 없음)를 **UI에 노출하는 것**이 이 실험 사이트의 요점이다. 그래서 홈에 재작성 결과 칩 줄과 6단계 사다리(1·2만 활성)를 두었다. 코퍼스는 배색사전 16쌍이라 문서의 "60%는 2단계에서 끝난다"에 정확히 해당한다.

문서의 비용·지연 수치는 원문 저자 주장이고 벤치마크 근거가 없으므로, 화면에는 `BM25 8ms` 정도만 자리표시자로 넣고 `$0.001/쿼리` 류는 빼놨다.

### 타이포

`Gowun Batang`(제목) + `IBM Plex Sans KR`(본문) + `IBM Plex Mono`(헥스·수치). 헥스를 모노로 두는 게 색 도구에서는 의미가 있다. Inter/Roboto/Arial 회피.

**반영하지 않은 지적과 이유:**

- *"빨강 × 흑록은 D형이 아니라 B형"* — 배색사전 ⑮ 는 원 분류가 D형(톤 위계 극단)이다. 코퍼스가 진실 원천이므로 유지.
- *"세이지그린 × 연분홍은 명도차가 커서 D형"* — 배색사전 ① 은 A형이다. 원 분류 유지하되, 화면의 자기모순(5:5 문장)만 고쳤다.
- *"아이보리 × 연하늘은 정확한 보색이 아니라 분할보색"* — 맞지만 화면에서 그 쌍을 "보색"이라 부르지 않는다. 필터 범례의 A형 정의에 걸린 것이라 초안 단계에서 넘긴다.
- *"파랑이 UI 강조색이면서 동시에 추천 조합의 구성색이라 의미 충돌"* — 실제 문제다. 다만 뉴트럴 무대를 유지하면서 강조색을 색상환의 어디에 둬도 16쌍 중 하나와는 겹친다. 구현 단계에서 "추천 스와치에는 UI 색을 안 쓴다"는 규칙 대신 **스와치에 테두리·라벨을 붙여 UI 면과 구분**하는 쪽으로 푸는 게 낫다고 본다.

안 된 것 — 캔버스를 브라우저로 직접 확인하지 못했다. 높이는 요소 높이 합산으로 추정해 여유를 뒀다(Main 1560 / History 1040 / Saved 1120). 한글 줄바꿈이 예상보다 한 줄 더 생기면 하단이 잘릴 수 있으니, 열어보고 잘리면 `canvas.json` 의 `h` 만 올리면 된다.

## 재시드 방법

`design/` 에서:

```bash
node "$DESIGN_SKILL/seed-canvas.mjs" --template "$DESIGN_SKILL/payload.template.html" --out tonefirst-color-canvas.html --title "톤먼저 색 추천 초안" --artboard Main.dc.html --artboard History.dc.html --artboard Saved.dc.html --canvas canvas.json
```

`$DESIGN_SKILL` 은 `/design` 스킬 번들의 `design/` 디렉터리다. **버전이 올라가면 경로가 바뀌므로
문서에 고정해 적지 않는다.** 돌리기 전에 셸에서 잡는다:

```bash
base=$(cygpath -u "${TMPDIR:-$TEMP}" 2>/dev/null || echo "${TMPDIR:-/tmp}")
hit=$(find "$base/claude/bundled-skills" -name seed-canvas.mjs 2>/dev/null | sort | tail -1)
[ -n "$hit" ] && export DESIGN_SKILL=$(dirname "$hit") || echo "번들 못 찾음 — /design 을 다시 호출한다"
```

없으면 `/design` 을 다시 호출해 재추출한다.
