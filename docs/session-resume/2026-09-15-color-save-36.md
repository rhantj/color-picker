## 무엇을 했나

대표 지시: "코드 및 색상 탭에서도 저장되게 하고 탭을 바꾸면 채팅창이 초기화 되도록". 35단계가 남긴 F1(저장 없음)을 닫고,
탭이 바뀌면 검색창을 비운다.

**쉽게 말하면** — 색 탭의 구조 카드에도 "이 배색 저장" 버튼이 생겼고, 짝 카드에는 "조합 저장" 이 생겼다. 저장 요청에 색을
싣지 않는다 — 구조 카드는 **씨앗 id 를 `hex-E07A5F` 꼴로** 보내고 서버가 그 헥스로 색을 다시 계산한다. 그래서 `/saved`·언리얼·
유니티 내보내기가 파생 항목과 똑같은 길로 돈다. 탭 버튼을 누르면 검색창의 글이 지워진다(같은 탭을 다시 누르면 안 지워진다).

## 왜 그렇게 했나

- **새 저장 경로를 안 만들었다.** `saveDerived` 는 `resolve(seedId, structureId, mode)` 를 밖에서 받는다. 씨앗 id 꼴만 하나 더 알면
  덮어쓰기·이어받기·재질 검증·`/saved`·내보내기가 전부 그대로다. 새 `kind` 를 만들면 그 다섯 곳이 다 갈라진다.
- **씨앗 id 는 `hex-RRGGBB`, `#RRGGBB` 는 거부.** 엔진 내보내기 id 가 `${seedId}-${structureId}-${mode}` 라 `#` 이 들어가면 자산
  이름·URL 에서 깨진다. `#` 붙은 씨앗은 400 이다(S36-G1 · 음성 대조로 확인).
- **씨앗 풀 쌍도 저장하되 지어내지 않는다.** 풀은 원명·헥스뿐(`seeds.js` 규칙). `savePalette` 조회에 풀을 더하면 `type`·`summary`
  가 없어 `/saved` 가 "유형 모름" 으로 그린다 — 24단계 `savedFields` 가 그 경우를 이미 다룬다. 유형을 D 로 지어내는 변형은 게이트가 잡는다.
- **재질은 기본 배정.** 헥스에는 인상이 없다. `selectFinishes` 에 빈 질의를 주면 폴백(기본표)만 낸다 — 17단계 "질의 없으면 미호출" 경로.
  응답에 `model`·`error` 키를 안 실어 S35-G4(Ollama 흔적 없음)를 지킨다.
- **탭 전환은 검색창만.** 결과는 탭마다 남긴다(34단계 결정). "채팅창 초기화" 를 검색창으로 읽었다.
- **버린 대안**: (a) 색 탭 전용 `POST /api/saved/color` — 위 다섯 곳 중복. (b) 풀 쌍은 저장 불가로 두기 — 짝 40쌍 중 24쌍에 버튼이
  없게 되고, 이유를 사용자가 알 수 없다. (c) 짝 카드에 비율 슬라이더 — `/saved` 에서 고칠 수 있어 안 넣었다.
