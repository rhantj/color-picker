# Git Bash 의 curl 로 보낸 한글이 깨져 Claude 가 엉뚱하게 읽는다

## 증상

`curl -d '{"text":"비 오는 날 오래된 서점, …"}'` 로 `/api/chat` 을 불렀더니 서로 다른 두 문장이 **거의 같은 의도**("밝고 시원한 파랑 계열")로
읽혔다. 서버 · 모델 문제처럼 보였다.

## 원인 (추정)

Windows Git Bash 에서 curl 인자로 넘긴 한글이 UTF-8 이 아닌 코드페이지로 넘어가 서버가 깨진 문자열을 받았다. 같은 문장을 Node
`fetch` 로 보내자 정상으로 읽혔다(서점 → 회청색 + 주황 포인트) — 그래서 서버 쪽은 아니다. 인코딩을 바이트로 확인하지는 않았다.

## 해결 / 우회

한글 요청은 Node 스크립트(`fetch` + `JSON.stringify`)로 보낸다. 브라우저 화면으로 확인하는 것도 같다.

## 재발 방지

없음. 측정 스크립트를 쓸 때 이 문서를 떠올린다.
