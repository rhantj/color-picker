# 전체 러너에서 "회귀" 게이트가 흔들린다 (S27-G7 EADDRINUSE · S40-G9)

42단계에서 `scripts/run-gates.mjs`(open-work I7)로 288개를 처음 돌렸을 때.

## 증상

1. 기준선(main, 42단계 전)과 42단계 첫 두 번의 실행에서 `S27-G7` · `S34-G10` · `S39-G10` 이 실패. `S27-G7` 원문:

   ```
   Error: listen EADDRINUSE: address already in use 0.0.0.0:4358
   ```

   단독으로 돌리면 셋 다 통과.
2. 회귀 게이트를 맨 끝에 혼자 돌리게 고친 뒤(아래)에도 `S40-G9` 이 한 번 실패 — 안쪽 `S39-G10` 이 `실패 (1)`. 출력이 잘려 어느 게이트인지
   안 보였다. 바로 앞에서 `S39-G10` 단독은 통과(183초)했고, `S40-G9` 단독 재실행도 통과(약 6분).

## 원인

1. **확인됨.** "회귀" 게이트(S31-G3 · S34-G10 · S39-G10 · S40-G9 …)는 다른 검사기를 통째로 다시 돌린다. 러너가 그것을 다른 일꾼과
   나란히 돌리면, 같은 검사기(예: check-stage27 의 고정 포트 4358)가 두 군데서 동시에 떠 포트가 부딪힌다. 또 기준선 첫 실행에서는
   러너의 게이트당 2분 제한이 회귀 게이트(3~6분)를 죽였다.
2. **모름(추정).** 안쪽 S39-G10 이 묶은 게이트 중 시간 게이트("1초 안" 류)가 흔들렸을 수 있다. 재현하지 못했다.

## 해결 / 우회

- 러너가 회귀 게이트(제목이 "… 회귀 —" 이거나 "게이트 N개가 그대로 통과")를 **맨 끝에 하나씩** 돌린다. 게이트당 제한 10분.
- 2번은 우회만 — 실패한 회귀 게이트는 단독으로 다시 돌려 확인한다.

## 재발 방지

- 러너 주석에 이유를 적었다. 러너를 다른 게이트 실행(변형 검사 등)과 **겹치게 돌리지 않는다** — 그때도 포트가 부딪혔다(S7-G2 · S35-G4).
- 2번은 없음. 다시 나면 `S40-G9` 이 안쪽 실패의 꼬리를 더 길게 찍게 고친다.
