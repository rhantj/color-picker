# S7-G4 가 main 에서도 실패한다 (막힌 채 넘어감)

## 증상

```
S7-G4_FAIL recordTurn 의 실패 처리를 찾지 못했다 / run 이 대화 확인(ready)을 기다리지 않는다 — 경합이 생긴다
```

41단계 작업 중 전체 게이트를 돌리다 발견했다. **41단계 변경과 무관하다** — 같은 날 main(`1dc4cac`)을 임시 워크트리로
꺼내 돌려도 똑같이 실패했다 `[실측]`.

## 원인 (추정)

`scripts/check-stage7.mjs` 의 S7-G4 는 `public/app.js` 소스에서 `recordTurn(...).catch(` 와
`async function run(...) ... await ready;` 모양을 정규식으로 찾는다. 39단계(탭 셋을 지우고 채팅창 하나로)에서
화면 코드가 크게 바뀌며 그 모양이 사라진 것으로 보인다 — 기능이 서버(`/api/chat`)로 옮겨 갔는지, 정말 빠졌는지는
확인하지 않았다 `[판단]`. 40단계 기록의 "게이트 267 전부 통과" 와 어긋나는데, 그때 이 게이트를 안 돌렸을 가능성이 있다.

## 해결 / 우회

없음. 41단계는 이 게이트를 건드리지 않았다. `open-work.md` I6 에 올렸다.

## 재발 방지책

없음 — 전체 게이트를 한 번에 돌리는 러너가 저장소에 없어서(open-work I7) 한 단계의 "전부 통과" 가 실제로 전부를
돌렸는지 확인할 방법이 없다. 러너를 두면 막힌다.
