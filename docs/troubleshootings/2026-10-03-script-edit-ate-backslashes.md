# 스크립트로 고친 코드에서 역슬래시가 사라진다

42 · 43단계에서 Node 스크립트(`fs.readFileSync` → `replace` → `writeFileSync`)로 파일을 고칠 때 두 번 났다.

## 증상

1. `scripts/run-gates.mjs` — `\d+` 로 넣으려던 정규식이 `d+` 로 커밋됐다(`eb1e075` 까지). 회귀 게이트 S25-G4 가 회귀로 분류되지 않았다.
2. `scripts/check-stage43.mjs` — `/\.expand__grid\[hidden\]\s*…/` 가 `/.expand__grid[hidden]s*{s*…/` 로 들어가 S43-G10 이 늘 실패했다.
   같은 파일에 `"\u0000"` 이 **실제 NUL 문자**로 들어가 `file` 이 "binary data" 로 봤다.

## 원인

고칠 내용을 JS **템플릿 문자열**(백틱)에 담았다. 템플릿 문자열은 `\.` · `\s` · `\[` 의 역슬래시를 지우고(모르는 이스케이프), `\u0000` 은
그 문자로 바꾼다. 1번은 치환 뒤 결과를 확인하지 않아 커밋까지 갔다.

## 해결

- 1번은 43단계에서 `\d+` 로 고쳤다. 2번은 `String.raw` 와 문자 코드로 다시 썼다.
- 정규식 · 이스케이프가 든 코드는 **편집 도구(Edit)로 직접** 고친다. 스크립트로 고쳤으면 `grep` 으로 결과 줄을 꼭 본다.

## 재발 방지

위 규칙. 게이트 파일은 `file` 로 텍스트인지 본다. 게이트 자체가 늘 실패하면 그 게이트의 정규식부터 의심한다.
