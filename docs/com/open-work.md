17단계까지 끝난 시점(2026-09-07)에 남아 있는 것을 한자리에 모았다. 세션 재개 문서마다 흩어져
있던 "열려 있는 것" 을 합쳐 **하나만 골라 바로 시작할 수 있게** 정리한 것이다.

**이 파일은 살아 있는 목록이다.** 항목을 끝내면 지우고, 새로 생기면 더한다. 각 항목의 자세한
맥락은 그 항목을 만든 세션 재개 문서에 있다.

([세션 재개 문서](../session-resume/2026-09-13-honest-status-25.md)).

**A·C·D 묶음이 전부 닫혔다.** 사용자가 못 하던 일이 없고, 읽히지 않던 배색도 없고, 말과 실제가
어긋나던 자리도 없다.

**남은 것은 B 묶음뿐이다 — 전부 대표님이 눈으로 보셔야 닫힌다.**

| 묶음 | 무엇 | 누가 |
|---|---|---|
| **B1~B3** | 러프니스·EV 값, PBR 범위, 공기원근의 어두운 모드 | **대표님이 게임 엔진에서 보셔야** 닫힌다. 값을 알려 주시면 반영은 작다 (`EV_MAX` 는 세 곳을 함께 고친다) |

**게이트로 안 만들고 남긴 것 하나** — `aerial` 의 "층끼리 먼 쪽이 덜 대비된다" 는 상대 순서는
32/32 로 지켜지지만 검사 게이트가 없다(24단계가 남김). 필요하면 별도 단계로 잡는다.

**C2 는 24단계 리뷰를 닫으면서 함께 닫혔다** — `S24-G6` 이 자기 파일만 보던 것을 **git
이력과 대조**하도록 고쳤다. 자기 파일만 보는 검사는 원리적으로 자기참조라 못 잡는다는 것이
그 리뷰에서 드러났고, **고정점을 어디서 읽느냐까지 같은 함정**이라는 것은 2차 리뷰가 잡았다.
지금은 게이트가 git 에게 직접 물어 고정점을 구한다. 남은 것은 git 이력을 못 읽는 환경뿐이고,
그때는 조용히 통과하지 않고 실패한다.
